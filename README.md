# House-Price-Prediction-ML
House Price Prediction Using Machine Learning and Python is a machine learning project that predicts house prices based on property features such as area, bedrooms, bathrooms, garage capacity, and overall quality. Built using Python, Scikit-learn, and Streamlit, it provides fast and accurate price predictions through an interactive web application.
# 🏠 House Price Prediction Using Machine Learning and Python

This project is a Machine Learning-based web application that predicts the selling price of a house based on various property features such as lot area, number of bedrooms, bathrooms, garage capacity, overall quality, basement area, neighborhood, and year built. The objective of the project is to provide fast, reliable, and accurate house price predictions, helping buyers, sellers, investors, and real estate professionals make informed decisions.

The project uses the **Ames Housing Dataset**, which contains 1,460 residential property records with 80 different features. Data preprocessing techniques such as data cleaning, feature selection, and feature engineering are applied to improve model performance. Multiple regression algorithms, including **Linear Regression**, **Decision Tree Regressor**, **Random Forest Regressor**, and **Gradient Boosting Regressor**, are trained and evaluated using performance metrics such as **R² Score, Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE)**. Based on the evaluation results, the **Random Forest Regressor** is selected as the final model due to its superior prediction accuracy.

The trained model is deployed using **Streamlit**, providing a simple and interactive web interface where users can enter property details and instantly receive an estimated house price. The project demonstrates the complete machine learning workflow, including data collection, preprocessing, exploratory data analysis (EDA), model training, evaluation, deployment, and prediction.

## 🚀 Features

* Predicts house prices based on multiple property attributes.
* Data preprocessing and feature engineering for improved accuracy.
* Comparison of multiple machine learning regression models.
* Interactive Streamlit web application for real-time predictions.
* Performance evaluation using R² Score, MAE, and RMSE.
* Easy-to-use interface for quick and reliable price estimation.
